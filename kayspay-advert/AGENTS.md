# KSP Adverts - Agent Rules

## Scope

This repository is only for KaysPay marketing, social media, product design, video editing, image generation, voice-over, music, captions, and campaign exports. Never modify the KaysPay application repository from this workspace.

## Approval

- Show or describe a draft direction before major campaign changes.
- Preserve approved exports and create versioned replacements.
- Do not publish, upload, post, or send content without explicit approval.

## Security

- Never copy `.env` files, API keys, server credentials, customer data, transaction data, NIN, BVN, phone numbers, or private analytics into this repository.
- Use fictional or clearly illustrative UI data in marketing visuals.
- Do not make guaranteed financial, investment, availability, security, or performance claims.

## Brand

- Primary green: `#1A5C3A`
- Dark green: `#0F3D27`
- Mint: `#D6F0E3`
- White: `#FFFFFF`
- Amber accent: `#F59E0B`
- Core message: `Pay smarter. Live easier.`

## Production

- Keep key text inside platform-safe margins.
- Maintain readable captions and accessible contrast.
- Use Nigerian English by default for Nigerian campaigns.
- Use licensed, original, or explicitly approved music and imagery.
- Run `npm.cmd run lint` before final video rendering.
- Verify duration, resolution, audio presence, and file integrity after rendering.
